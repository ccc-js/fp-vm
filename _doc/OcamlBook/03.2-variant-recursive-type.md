# 3.2 variant 與遞迴型別

variant（代數資料型別）是 OCaml 的招牌：用有限個建構子精確建模領域。

## 1. 基本 variant

```ocaml
type color = Red | Green | Blue

type shape =
  | Circle of float
  | Rect of float * float
  | Point

let area = function
  | Circle r -> 3.14159 *. r *. r
  | Rect (w, h) -> w *. h
  | Point -> 0.0
```

建構子大寫開頭，`of` 攜帶資料。無參數者如 `Red` 本身即值。

## 2. 遞迴型別：運算式樹

```ocaml
type expr =
  | Num of int
  | Var of string
  | Add of expr * expr
  | Mul of expr * expr
  | Neg of expr

let rec eval env = function
  | Num n -> n
  | Var v -> List.assoc v env
  | Add (a, b) -> eval env a + eval env b
  | Mul (a, b) -> eval env a * eval env b
  | Neg a -> - eval env a
```

多型 variant：

```ocaml
type 'a tree = Leaf | Node of 'a tree * 'a * 'a tree

let rec size = function
  | Leaf -> 0
  | Node (l, _, r) -> size l + 1 + size r
```

## 3. 參數多型與約束

```ocaml
type ('k, 'v) table = (('k * 'v) list)
type 'a option = None | Some of 'a   (* 標準定義 *)
type ('a, 'e) result = Ok of 'a | Error of 'e
```

## 4. 型別別名 vs 新型別

```ocaml
type user_id = int              (* 別名：與 int 互通 *)
type age = int

type uid = Uid of int           (* 單建構子包裝：與 int 不互通，更安全 *)
let show_uid (Uid n) = string_of_int n
```

API 邊界建議用包裝型別避免 `user_id` 與 `order_id` 混淆。

## 練習

1. 為 `shape` 加 `Triangle of point * point * point` 並實作面積。
2. 寫 `simplify : expr -> expr`（`Add (Num 0, e) → e` 等）。
3. 定義二元搜尋樹 `insert`、`mem`、`inorder`。

## 常見錯誤

- 建構子參數需一個 tuple：`Rect (w, h)` 正確，`Rect w h` 在定義為 `of float * float` 時錯誤（多參用 `*` 合併為一個 tuple 參數）。
- 忘記處理某分支：編譯器警告 `non-exhaustive`，應補上。
