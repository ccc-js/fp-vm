# 6.1 多型變體、物件與類別簡介

官方 OCaml 除 variant / module 外，還有多型變體（polymorphic variant）與物件系統。本節定位為「讀懂即可」，實務以前兩者為主。

## 1. 多型變體：免宣告的 variant

```ocaml
let f = function `Circle r -> 3.14 *. r *. r | `Rect (w, h) -> w *. h

let a = `Circle 2.0     (* [> `Circle of float | `Rect of ... ]，結構型別 *)
let b = `Rect (3.0, 4.0)
```

優點：不同模組可各自擴充同一組 `` `Tag ``，不需統一宣告。缺點：錯誤訊息較長，過度使用難維護。

型別約束寫法：

```ocaml
let area : [ `Circle of float | `Rect of float * float ] -> float = function
  | `Circle r -> 3.14 *. r *. r
  | `Rect (w, h) -> w *. h
```

適用：小型 DSL、錯誤碼合併、需開放擴充的 AST。

## 2. 物件：結構型別的行多型

```ocaml
let p = object
  val mutable x = 0
  method get = x
  method bump = x <- x + 1
end

let () = p#bump; Printf.printf "%d\n" p#get
```

物件型別由方法結構決定：`< get : int; bump : unit >`。不同類別只要方法相容即可互換。

```ocaml
let show (o : < name : string; .. >) = o#name
(* .. 表示「至少有 name」，其餘忽略：行多型 *)
```

## 3. 類別簡介

```ocaml
class counter ?(start=0) () = object
  val mutable n = start
  method next = n <- n + 1; n
  method reset = n <- start
end

let c = new counter ~start:10 ()
```

實務建議：

- 優先用 module + record + 函式，而非類別繼承。
- 物件僅用於：需結構子型別的 UI 元件、插件介面、與 OO 函式庫互操作。
- Jane Street 風格幾乎不用物件/類別，仍是完整 OCaml。

## 練習

1. 用多型變體合併兩個模組各自的錯誤型別。
2. 寫一個 `< draw : unit >` 物件串列並迭代呼叫。
3. 將同一邏輯分別用 variant 與物件實作，比較錯誤訊息。

## 常見錯誤

- 多型變體漏分支不會像普通 variant 那樣精確警告：加顯式型別約束。
- 物件方法呼叫用 `#` 而非 `.`。
