# 3.3 list、array 與字串

三種序列：不可變鏈結串列 `list`、可變 `array`（+ 5.4 不可變 `iarray`）、不可變 `string`/`bytes`。

## 1. list

```ocaml
let nums = [1; 2; 3; 4; 5]     (* int list，注意分號 *)
let empty : int list = []

let head_ex = List.hd nums     (* 1，空串列會拋 Failure *)
let tail = List.tl nums

let cons = 0 :: nums           (* :: 前插，O(1) *)
let cat = [1; 2] @ [3; 4]      (* @ 串接，O(n)，避免在迴圈內用 *)
```

常用（全在 `List` 模組）：

```ocaml
List.length nums
List.map string_of_int nums
List.filter (fun x -> x mod 2 = 0) nums
List.fold_left ( + ) 0 nums
List.iter print_endline ["a"; "b"]
List.init 5 (fun i -> i * i)    (* [0;1;4;9;16] *)
```

模式匹配是 list 的自然寫法（詳見 3.4）。

## 2. array：可變、隨機存取

```ocaml
let a = [| 1; 2; 3 |]          (* int array *)
let () = a.(0) <- 99           (* 修改 *)
let v = a.(1)                  (* 讀取 *)

Array.length a
Array.map (fun x -> x * 2) a
Array.init 5 (fun i -> i)
Array.make 3 "hi"              (* [|"hi";"hi";"hi"|] *)
```

`list` vs `array`：

|  | list | array |
| --- | --- | --- |
| 可變 | 否 | 是 |
| 前插 | O(1) | O(n) |
| 隨機存取 | O(n) | O(1) |
| 模式匹配 | 極佳 | 較弱 |

## 3. 不可變陣列 iarray（5.4+）

```ocaml
let ia = [: 1; 2; 3 :]         (* 'a iarray *)
let v = ia.:(0)                (* 讀取，不可寫 *)
let l = Iarray.to_list ia
```

需要函數式持久陣列時用 `iarray`；高效可變仍用 `array`。

`floatarray` 針對密集浮點優化，大量數值運算可考慮。

## 4. string 與 bytes

```ocaml
let s = "hello"
String.length s                (* 5 *)
s.[0]                          (* 'h' *)
String.sub s 1 3               (* "ell" *)
String.split_on_char ',' "a,b,c"
String.concat "; " ["a"; "b"]

let b = Bytes.of_string s
Bytes.set b 0 'H'
Bytes.to_string b              (* "Hello" *)
```

字串不可變，要原地修改先轉 `Bytes`。UTF-8 多位元組字元不要用 `.[i]` 逐位元組切。

## 常見錯誤

- `[1, 2, 3]` 是含一個 tuple 的串列，不是 `[1; 2; 3]`。
- `a.[0]` 是字串索引，`a.(0)` 才是陣列索引。
