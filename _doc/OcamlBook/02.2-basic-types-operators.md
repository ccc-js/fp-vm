# 2.2 基本型別與運算子

官方 OCaml 是強靜態型別：`int` 與 `float` 絕不隱式轉換。

## 1. 基本型別

| 型別 | 範例 | 備註 |
| --- | --- | --- |
| `int` | `42`, `-7`, `0xFF`, `1_000_000` | 63 位（64 位平台），`_` 可分隔 |
| `float` | `3.14`, `2.`, `1e-3` | 雙精度，字面值需含 `.` 或 `e` |
| `string` | `"hi\n"` | 不可變，UTF-8（5.3+ 原始碼預設 UTF-8） |
| `bool` | `true`, `false` | `&&`、`||` 短路 |
| `char` | `'a'`, `'\n'` | 單字元，與字串不同 |
| `unit` | `()` | 副作用函式的回傳 |

```ocaml
let i : int = 42
let f : float = 3.14
let s : string = "hello"
let b : bool = true
let u : unit = ()
```

## 2. 運算子分兩套

```ocaml
1 + 2 * 3 / 2 - 1        (* int *)
1. +. 2. *. 3. /. 2. -. 1.  (* float，注意點 *)
mod                     (* 取餘，僅 int：5 mod 3 = 2 *)
```

比較：

```ocaml
1 = 1       (* 結構相等 *)
1 <> 2      (* 不等 *)
1 < 2 && 3.0 >= 2.5
```

字串連接用 `^`：

```ocaml
"con" ^ "cat"          (* "concat" *)
string_of_int 42 ^ "!"
```

## 3. 轉換函式

```ocaml
string_of_int 42        (* "42" *)
int_of_string "42"      (* 42，失敗拋 Failure *)
string_of_float 3.14
float_of_int 7          (* 7. *)
int_of_float 3.99       (* 3，截斷 *)
bool_of_string "true"
```

安全解析用 `int_of_string_opt`（回傳 `option`，見 4.3）：

```ocaml
int_of_string_opt "42"   (* Some 42 *)
int_of_string_opt "hi"   (* None *)
```

## 4. `char`、`string` 常用

```ocaml
String.length "hello"   (* 5，位元組數；Unicode 字元數需用 Uutf 等函式庫 *)
"hello".[1]             (* 'e' *)
Char.uppercase_ascii 'a'
String.sub "hello" 1 3  (* "ell" *)
```

## 練習

1. 計算 `float_of_int 7 /. 2.0` 與 `7 / 2` 差異。
2. 用 `Printf.sprintf "%05d|%.2f"` 格式化 `42`、`3.14159`。
3. 試 `int_of_string " 42 "` 與 `int_of_string_opt` 行為。

## 常見錯誤

- `Error: This expression has type float but ... int`：混用 `+` 與 `+.`。
- `String.length` 對中文回傳位元組數而非字元數。
