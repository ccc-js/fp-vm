# 5.1 module、簽章與封裝

模組是 OCaml 管理大型程式的命名空間 + 抽象邊界。檔即模組，簽章即介面。

## 1. 檔案即模組

```text
lib/
├── dune
├── stack.ml      → 模組 Stack
└── stack.mli     → 模組 Stack 的簽章（介面，可選但推薦）
```

`stack.ml`：

```ocaml
type 'a t = 'a list
let empty = []
let push x s = x :: s
let pop = function [] -> None | x :: rest -> Some (x, rest)
let size = List.length
```

`stack.mli`：

```ocaml
type 'a t
val empty : 'a t
val push : 'a -> 'a t -> 'a t
val pop : 'a t -> ('a * 'a t) option
val size : 'a t -> int
```

`.mli` 隱藏實作（`'a t` 變抽象型別），外部不能假設它是 `list`。

## 2. struct / sig 與封裝

```ocaml
module type STACK = sig
  type 'a t
  val empty : 'a t
  val push : 'a -> 'a t -> 'a t
  val pop : 'a t -> ('a * 'a t) option
end

module ListStack : STACK = struct
  type 'a t = 'a list
  let empty = []
  let push x s = x :: s
  let pop = function [] -> None | x :: rest -> Some (x, rest)
end
```

`module M : S` 封裝：`S` 未列出的成員外部不可見。

## 3. open、include、局部 open

```ocaml
open Printf              (* 全域開啟，慎用，易污染 *)
include List             (* 把另一模組成員納入本模組 *)

let s = ListStack.(push 3 empty)   (* 局部 open，推薦 *)
let x = Stack.(empty |> push 1)    (* 同上 *)
let open String in length "hi"     (* let open ... in，作用域最小 *)
```

風格：函式庫內部可用 `open`，公開 `.mli` 避免 `open`（保持限定名清晰）。

## 4. 巢狀模組

```ocaml
module Geometry = struct
  type point = { x : float; y : float }
  module Vec = struct
    let add a b = { x = a.x +. b.x; y = a.y +. b.y }
    let norm2 p = p.x *. p.x +. p.y *. p.y
  end
  let origin = { x = 0.0; y = 0.0 }
end

let p = Geometry.Vec.add Geometry.origin { x = 1.0; y = 2.0 }
```

## 常見錯誤

- `.ml` 與 `.mli` 不一致：`Interface mismatch`，需同步更新。
- 頂層 `open` 太多導致 `Unbound value` 難以定位：改局部 open。
