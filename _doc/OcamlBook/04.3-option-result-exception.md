# 4.3 option、result 與例外處理

官方 OCaml 推薦：可預期的失敗用 `option` / `result`，真正的異常才用例外。

## 1. option：可能缺席

```ocaml
let safe_div a b = if b = 0 then None else Some (a / b)

match safe_div 10 2 with
| Some q -> Printf.printf "%d\n" q
| None -> print_endline "division by zero"
```

`Option` 模組（5.x 持續擴充）：

```ocaml
Option.map (fun x -> x + 1) (Some 3)   (* Some 4 *)
Option.value ~default:0 None           (* 0 *)
Option.bind (Some 3) (fun x -> safe_div 10 x)
List.filter_map (fun s -> int_of_string_opt s) ["1"; "hi"; "3"]  (* [1;3] *)
```

## 2. result：帶錯誤訊息

```ocaml
let parse_age n =
  if n < 0 then Error "negative"
  else if n > 150 then Error "too large"
  else Ok n

let show = function Ok n -> string_of_int n | Error m -> "error: " ^ m
```

`Result.bind` 與 `let*`（5.x 內建 binding operator）：

```ocaml
let ( let* ) = Result.bind

let check_even n = if n mod 2 = 0 then Ok n else Error "not even"

let process n =
  let* p = parse_age n in
  let* e = check_even p in
  Ok (e / 2)
```

`let+`（map）、`and+`（並行綁定）需自行定義（見 6.3 / Stdlib 範例）。

## 3. 例外：少用但要會

```ocaml
exception Empty_list
exception Http_error of int * string

let hd = function [] -> raise Empty_list | h :: _ -> h

try Printf.printf "%d\n" (hd [])
with
| Empty_list -> print_endline "empty!"
| e -> raise e   (* 未知例外繼續拋 *)
```

常用內建：`Failure`、`Invalid_argument`、`Not_found`、`Sys_error`。`failwith msg` 即 `raise (Failure msg)`。

`try ... with` 亦是表達式，可回傳值；`finally` 語義用 `Fun.protect`：

```ocaml
let with_in path f =
  let ic = open_in path in
  Fun.protect ~finally:(fun () -> close_in_noerr ic) (fun () -> f ic)
```

## 4. 選擇指南

| 情境 | 推薦 |
| --- | --- |
| 查表可能缺席 | `find_opt` + `option` |
| 解析、驗證、IO（可預期失敗） | `result` + `let*` 串接 |
| 斷言違反、資源耗盡、bug | 例外 |
| 跨層傳遞且需堆疊 | 例外 + `Printexc` / backtrace |

## 練習

1. 用 `Option.bind` 串 `safe_div 100 b` 再 `safe_div x c`。
2. 用 `result` + `let*` 寫三步驗證（正數→偶數→除以2）。
3. 用 `Fun.protect` 包裝檔案讀寫，確保關檔。

## 常見錯誤

- 對 `option` 直接 `Option.get`（空時拋例外）：優先 `value ~default` 或匹配。
- 濫用例外作流程控制（效能差、難追蹤）。
