# 5.3 標準函式庫導覽

Stdlib 隨編譯器附帶，無需安裝。5.5 新增約 60 個函式，本節列出最常用的子集。

## 1. 核心模組地圖

| 模組 | 用途 | 代表函式 |
| --- | --- | --- |
| `List` | 不可變串列 | `map`、`filter`、`fold_left`、`find_opt`、`init` |
| `Array` / `Iarray` | 可變 / 不可變陣列 | `make`、`init`、`map`、`to_list` |
| `Option` / `Result` | 缺席 / 錯誤 | `map`、`bind`、`value ~default` |
| `String` / `Bytes` / `Char` | 文字 | `split_on_char`、`concat`、`starts_with` |
| `Hashtbl` / `Map` / `Set` | 字典集合 | `add`、`find_opt`、`mem` |
| `Queue` / `Stack` | 佇列堆疊 | `push`、`pop`、`take_opt` |
| `Seq` | 惰性序列 | `map`、`filter`、`take`、`unfold` |
| `Printf` / `Format` | 格式化 | `printf`、`sprintf`、`asprintf` |
| `Sys` / `Unix` / `Filename` | 系統 | `argv`、`getenv_opt`、`concat` |
| `Fun` / `Float` / `Int` | 工具 | `protect`、`id`、`compare` |
| `Pair` / `Pqueue`（5.4+） | 對組 / 優先佇列 | `map_fst`、`pop_min` |

完整 API 見 <https://ocaml.org/manual/5.5/api/>。

## 2. 字串與格式化

```ocaml
String.starts_with ~prefix:"https://" "https://ocaml.org"  (* true，5.x *)
String.ends_with ~suffix:".ml" "hello.ml"
String.contains "hello" 'e'
String.uppercase_ascii "hi"

Printf.sprintf "%05d|%-6s|%.2f" 42 "ab" 3.14159
```

## 3. 容器選擇

```ocaml
(* 小字典、需持久：Map *)
module SMap = Map.Make (String)
(* 大量可變、高速：Hashtbl *)
let h = Hashtbl.create 16
let () = Hashtbl.add h "a" 1
let v = Hashtbl.find_opt h "a"

(* 需順序+唯一：Set *)
module ISet = Set.Make (Int)
(* FIFO：Queue；LIFO：Stack *)
```

## 練習

1. 只用 `List`、`String`、`Printf` 寫 CSV 解析並格式化輸出。
2. 分別用 `Map` 與 `Hashtbl` 實作字頻統計，比較程式碼差異。
3. 查 `Seq` 文件，找出 `unfold` 與 `ints` 的簽章。

## 常見錯誤

- `Hashtbl` 預設不可持久、遍歷順序未定義：需順序用 `Map`。
- `String.get` 越界拋 `Invalid_argument`：先檢查長度或用 `get_opt`（若有）。
