# 5.2 functor

Functor 是「模組的函式」：輸入模組，輸出模組。標準函式庫 `Set`、`Map` 即典範。

## 1. 最小範例：MakeSet

```ocaml
module type ORDERED = sig
  type t
  val compare : t -> t -> int
end

module MakeSet (Ord : ORDERED) = struct
  type elt = Ord.t
  type t = elt list
  let empty = []
  let rec add x = function
    | [] -> [x]
    | y :: rest as s ->
        let c = Ord.compare x y in
        if c = 0 then s else if c < 0 then x :: s else y :: add x rest
  let rec mem x = function
    | [] -> false
    | y :: rest ->
        let c = Ord.compare x y in
        c = 0 || (c > 0 && mem x rest)
end

module IntOrd = struct
  type t = int
  let compare = compare
end

module IntSet = MakeSet (IntOrd)
let s = List.fold_left (fun acc x -> IntSet.add x acc) IntSet.empty [5;3;8;3]
```

匿名參數亦可：`MakeSet (struct type t = float let compare = compare end)`。

## 2. 標準 Set / Map 用法（實務直接用）

```ocaml
module IntSet = Set.Make (Int)
module StrMap = Map.Make (String)

let s = List.to_seq [3;1;2;3] |> IntSet.of_seq
let () = Printf.printf "mem 2=%b size=%d\n" (IntSet.mem 2 s) (IntSet.cardinal s)

let m =
  List.to_seq [("a", 1); ("b", 2)]
  |> StrMap.of_seq
  |> StrMap.add "c" 3

let () = match StrMap.find_opt "b" m with
  | Some v -> Printf.printf "b=%d\n" v
  | None -> print_endline "missing"
```

`Set.Make` / `Map.Make` 即官方提供的 functor，不必自造。

## 3. 含結果簽章的 functor

```ocaml
module MakeCounter (X : sig val start : int end) : sig
  val next : unit -> int
  val reset : unit -> unit
end = struct
  let c = ref X.start
  let next () = incr c; !c
  let reset () = c := X.start
end

module C = MakeCounter (struct let start = 100 end)
```

每次套用產生獨立狀態（generative）：`C1` 與 `C2` 的 `ref` 互不干擾。

## 4. 何時用 functor vs 函式參數

|  | functor | 高階函式 / first-class module |
| --- | --- | --- |
| 決定時機 | 編譯期 | 執行期 |
| 效能 | 零成本展開 | 微小間接成本 |
| 彈性 | 低（模組固定） | 高（可動態切換） |

資料結構、編解碼器選 functor；需執行期多型切換選 first-class module（見 6.3）。

## 常見錯誤

- 忘記 `compare` 語義（負/零/正），導致 `Set` 錯亂。
- functor 參數簽章不符：`does not match`，檢查 `type t` 是否一致。
