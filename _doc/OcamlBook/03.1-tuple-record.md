# 3.1 tuple 與 record

異質資料的兩種方式：匿名 tuple 與具名 record。

## 1. tuple

```ocaml
let p = (1, "one", true)       (* int * string * bool *)
let pair = (3, 4.5)            (* int * float *)

let x, y = pair                (* 解構 *)
let fst (a, _) = a
let snd (_, b) = b
```

tuple 最多用於臨時組合；超過 3–4 個欄位請用 record（可讀性）。

巢狀與標註：

```ocaml
let t : int * string = (42, "answer")
let nested = ((1, 2), (3, 4))
```

## 2. record 定義

```ocaml
type point = { x : float; y : float }

let origin = { x = 0.0; y = 0.0 }
let p1 = { x = 3.0; y = 4.0 }

let dist a b =
  sqrt ((a.x -. b.x) ** 2.0 +. (a.y -. b.y) ** 2.0)
```

存取 `p.x`，更新用 `with`（產生新值，原值不變）：

```ocaml
let p2 = { p1 with y = 10.0 }
let p3 = { origin with x = 1.0 }
```

## 3. 可變欄位

預設欄位不可變；需可變才標 `mutable`：

```ocaml
type counter = { mutable n : int; name : string }

let c = { n = 0; name = "hits" }
let () = c.n <- c.n + 1        (* <- 賦值 *)
```

> 大型可變狀態優先用 `ref` 或明確的狀態傳遞，而非到處 `mutable`。

## 4. 解構與模式

```ocaml
let show { x; y } = Printf.sprintf "(%.1f, %.1f)" x y
let move dx { x; y } = { x = x +. dx; y }

type user = { name : string; age : int }
let is_adult { age; _ } = age >= 18
```

欄位名稱全域唯一（同模組內）。衝突時用模組限定（見第 5 章）。

## 練習

1. 定義 `type rect = { lo : point; hi : point }` 並寫 `area`。
2. 用 `{ r with ... }` 實作不可變的「移動點」。
3. 試 `mutable` 版與 `with` 版的差異：前者影響別名，後者不影響。

## 常見錯誤

- `The record field x belongs to ...`：欄位名拼錯或型別不符。
- 以為 `{ p with x = 1 }` 會修改 `p`（不會，是新值）。
