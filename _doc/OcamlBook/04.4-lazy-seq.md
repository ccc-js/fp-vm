# 4.4 延遲求值、Seq 與惰性結構

OCaml 預設嚴格求值；需要無限序列或昂貴計算延遲時用 `lazy` / `Seq`。

## 1. `lazy` 與 `Lazy.force`

```ocaml
let v = lazy (print_endline "computed!"; 42)
(* 此時尚未印出 *)
let x = Lazy.force v   (* 第一次才計算並印出 *)
let y = Lazy.force v   (* 第二次直接回傳快取值，不再印 *)
```

`lazy` 是語法，產生 `'a lazy_t`。注意副作用只執行一次。

## 2. `Seq`：惰性串列（標準函式庫）

```ocaml
let nats = Seq.ints 1               (* 1, 2, 3, ... 無限 *)
let first10 = Seq.take 10 nats |> List.of_seq  (* [1..10] *)

let squares = Seq.map (fun x -> x * x) (Seq.ints 1)
let even_squares = Seq.filter (fun x -> x mod 2 = 0) squares
let ans = Seq.take 5 even_squares |> List.of_seq  (* [4;16;36;64;100] *)
```

`Seq` 常用：`map`、`filter`、`take`、`drop`、`fold_left`、`find`、`for_all`、`unfold`：

```ocaml
let fibs =
  Seq.unfold (fun (a, b) -> Some (a, (b, a + b))) (0, 1)

let _ = Seq.take 8 fibs |> List.of_seq  (* [0;1;1;2;3;5;8;13] *)
```

## 3. 自訂惰性串列 vs `Seq`

教學用自訂型別理解概念，實務直接用 `Seq`：

```ocaml
type 'a llist = Nil | Cons of 'a * 'a llist Lazy.t

let rec lfrom n = Cons (n, lazy (lfrom (n + 1)))
let rec ltake n = function
  | Nil -> []
  | Cons (h, t) -> if n <= 0 then [] else h :: ltake (n - 1) (Lazy.force t)
```

## 4. 效能提醒

- `Seq` 每次 `force` 有閉包成本，熱迴圈大量數值仍用 `array` / `for`。
- 無限 `Seq` 不要 `List.of_seq`（永不終止），先 `take`。
- `Seq` 是單次消費語義？官方 `Seq` 可重複遍歷（底層函式可重呼），但含副作用的 `unfold` 重跑會重算。

## 練習

1. 用 `Seq.unfold` 產生 Collatz 序列。
2. 用 `lazy` 快取昂貴的檔案解析結果。
3. 比較 `List`（嚴格）與 `Seq`（惰性）在 `take 5 (map f [1..1e7])` 的記憶體差異。

## 常見錯誤

- `let x = lazy ...` 後忘記 `force`，拿到 `'a lazy_t` 而非 `'a`。
- 在 `Seq` 管線中放 `print` 副作用，遍歷次數不如預期（惰性導致延後/重複執行）。
