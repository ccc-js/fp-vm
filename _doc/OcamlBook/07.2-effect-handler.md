# 7.2 Effect Handler

代數效應（algebraic effect）讓你自訂控制流：同一個計算可被暫停、恢復、注入不同解釋。5.3+ 支援深層 handler 語法。

## 1. 最小範例：Reader

```ocaml
open Effect
open Effect.Deep

type _ Effect.t += Ask : int Effect.t

let computation () =
  let x = perform Ask in
  let y = perform Ask in
  x + y

let () =
  try_with computation ()
    { effc = fun (type a) (e : a Effect.t) ->
        match e with
        | Ask -> Some (fun (k : (a, _) continuation) -> continue k 10)
        | _ -> None }
  |> Printf.printf "result=%d\n"  (* 20 *)
```

`perform Ask` 暫停計算，handler 以 `10` 恢復；兩次 `Ask` 各得 10。

## 2. State 效應

```ocaml
open Effect
open Effect.Deep

type _ Effect.t += Get : int Effect.t | Put : int -> unit Effect.t

let prog () =
  let x = perform Get in
  perform (Put (x + 1));
  perform Get

let run_state init f =
  let state = ref init in
  try_with f ()
    { effc = fun (type a) (e : a Effect.t) ->
        match e with
        | Get -> Some (fun k -> continue k !state)
        | Put v -> Some (fun k -> state := v; continue k ())
        | _ -> None }

let () = Printf.printf "state=%d\n" (run_state 41 prog)  (* 42 *)
```

## 3. 與例外、monad 的關係

| 機制 | 可恢復 | 用途 |
| --- | --- | --- |
| 例外 | 否（拋出即 unwind） | 錯誤 |
| `option`/`result` + `let*` | 程式化串接 | 可預期失敗 |
| Effect | 是（continuation 可多次/零次恢復） | 非確定、併發排程、依賴注入 |

Effect 是更底層的原語；`Eio`（下一節）即建於其上。一般應用直接用 `Eio`，不必手寫 handler。

## 4. 注意事項

- Effect 是單 Domain 內的控制流，跨 Domain 傳遞 continuation 受限。
- 不要用 Effect 作 covert 例外：handler 結構應清晰，文件註明會 `perform` 哪些效應。
- 舊教學的 `match_with` 已被 `try_with` / `match_with` 新 API 取代，以官方 5.5 手冊為準。

## 練習

1. 實作 `Yield : unit Effect.t`，寫一個協作式列印排程。
2. 用 Effect 實作非確定選擇（`Choose : bool Effect.t`，列舉所有解）。
3. 比較同一邏輯的 monad 版與 effect 版程式碼量。

## 常見錯誤

- 忘記 `continue k` 導致計算懸置。
- 在 handler 內再次 `perform` 同一效應造成無限遞迴。
