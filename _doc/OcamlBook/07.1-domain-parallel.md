# 7.1 Domain 並行與記憶體模型

OCaml 5.x 最大變革：多核並行。`Domain` 是真正的 OS 執行緒並行，不再受全域鎖限制。

## 1. Domain 基本用法

```ocaml
let work n =
  let rec loop i acc = if i > n then acc else loop (i + 1) (acc + i) in
  loop 1 0

let () =
  let d1 = Domain.spawn (fun () -> work 50_000_000) in
  let d2 = Domain.spawn (fun () -> work 50_000_000) in
  let r1 = Domain.join d1 in
  let r2 = Domain.join d2 in
  Printf.printf "%d %d\n" r1 r2
```

編譯與執行：

```bash
dune exec ./bin/main.exe
```

多核需 native 編譯（`ocamlopt` / dune 預設 release 即是）。

## 2. 記憶體模型與共享

- 每個 Domain 有獨立 minor heap，major heap 共享。
- 不可變資料可自由共享；可變（`ref`、`array`、`Hashtbl`）需同步。
- 內建同步：`Mutex`、`Semaphore`、`Condition`（`Stdlib` 即有）。

```ocaml
let m = Mutex.create ()
let counter = ref 0

let incr_safe () =
  Mutex.lock m;
  incr counter;
  Mutex.unlock m

let () =
  let ds = List.init 4 (fun _ -> Domain.spawn (fun () ->
    for _ = 1 to 100_000 do incr_safe () done)) in
  List.iter Domain.join ds;
  Printf.printf "counter=%d\n" !counter  (* 400000 *)
```

`Atomic` 用於無鎖計數：

```ocaml
let a = Atomic.make 0
let () = Atomic.incr a
let v = Atomic.get a
```

## 3. 效能實務

```ocaml
let parallel_map f l =
  let n = Domain.recommended_domain_count () in
  let chunk i = List.filteri (fun j _ -> j mod n = i) l in
  let ds = List.init n (fun i -> Domain.spawn (fun () -> List.map f (chunk i))) in
  List.concat_map Domain.join ds
```

- CPU 密集才用 `Domain`；IO 密集用 `Eio`（見 7.3）。
- `recommended_domain_count ()` 取得建議並行數。
- 避免 false sharing：不同 Domain 頻繁寫相鄰陣列元素會互相拖慢。

## 練習

1. 分別用 1 / 2 / 4 個 Domain 跑 `work`，量測加速比。
2. 將 `Atomic` 版與 `Mutex` 版計數器做效能對比。
3. 試著不加鎖並行 `incr`，觀察結果為何小於預期（data race）。

## 常見錯誤

- 在位元組碼（`ocamlc`）下並行效果差：切 release / native。
- 跨 Domain 共享 `Queue`、`Hashtbl` 未加鎖。
