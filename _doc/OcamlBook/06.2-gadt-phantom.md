# 6.2 GADT 與 phantom type

用型別索引表達「不變量」，讓非法狀態無法編譯。

## 1. phantom type：零成本標記

```ocaml
type ('a, 'kind) t = 'a
type even = Even
type odd = Odd

let of_int (n : int) : (int, even) t option =
  if n mod 2 = 0 then Some n else None
```

`'kind` 從未出現在右側，僅作標記。`Even` 與 `Odd` 是空型別，執行期無成本。

實例：區分 `user_id` 與 `order_id`（皆底層 `int` 但不可互換）：

```ocaml
type 'a id = Id of int
type user = User
type order = Order

let uid : user id = Id 1
(* let oid : order id = uid  (* 型別錯誤，擋下混用 *) *)
```

## 2. GADT：讓建構子回傳不同實例

```ocaml
type _ term =
  | Int : int -> int term
  | Bool : bool -> bool term
  | Add : int term * int term -> int term
  | If : bool term * 'a term * 'a term -> 'a term

let rec eval : type a. a term -> a = function
  | Int n -> n
  | Bool b -> b
  | Add (a, b) -> eval a + eval b
  | If (c, t, e) -> if eval c then eval t else eval e
```

`eval` 的回傳型別隨輸入 `a` 而定，普通 variant 做不到。`type a.` 是 locally abstract type，GADT 必備。

錯誤範例會被擋下：`Add (Bool true, Int 1)` 無法通過型別檢查。

## 3. 實務取捨

| 技術 | 成本 | 適用 |
| --- | --- | --- |
| 包裝型別 `Uid of int` | 極低 | ID、單位（公尺/秒） |
| phantom | 零 | 狀態機（未驗證/已驗證）、權限 |
| GADT | 理解成本高 | 表達式語言、typed SQL、protocol |

不要為小程式引入 GADT；先用普通 variant + 執行期檢查，痛點明確再升級。

## 練習

1. 用 phantom 實作 `('a, [`Locked | `Unlocked]) t`，只有 `Unlocked` 能讀。
2. 為 `term` 加 `Eq : 'a term * 'a term -> bool term`。
3. 觀察拿掉 `type a.` 後的錯誤訊息，理解其作用。

## 常見錯誤

- GADT 匹配忘記 `type a.` 導致 `This type ... is not generalized`。
- 過度設計：GADT 錯誤訊息對新手不友善，需完整註解。
