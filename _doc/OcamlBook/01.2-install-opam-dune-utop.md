# 1.2 安裝 opam、dune 與 utop

本節在 macOS / Linux 上建置 OCaml 5.5 開發環境。

## 1. 元件關係

```text
opam  → 套件與編譯器版本管理（類似 nvm + npm）
dune  → 建置系統（類似 cargo / cmake）
utop  → 互動式頂層（REPL，比 ocaml 更好用）
ocaml-lsp / ocamlformat → 編輯器支援與格式化
```

## 2. 安裝 opam

macOS（Homebrew）：

```bash
brew install opam
opam init --bare -y
```

Ubuntu / Debian：

```bash
sudo apt install opam build-essential
opam init --bare -y
```

初始化後建立 5.5 開關（switch）：

```bash
opam switch create 5.5.1
eval $(opam env)
ocaml -version   # 應顯示 5.5.1
```

> 公司網路需代理時：先設 `http_proxy` / `https_proxy` 再 `opam init`。

## 3. 安裝常用工具

```bash
opam install dune utop ocamlformat ocaml-lsp-server odoc -y
dune --version
utop -version
```

VS Code 擴充：`OCaml Platform`（含語法突顯、跳轉、inlay hint）。

## 4. 環境切換

```bash
opam switch list
eval $(opam env)        # 每開一個新 shell 都要執行
opam switch pin add .   # 在專案目錄鎖定版本（可選）
```

建議將 `eval $(opam env)` 加入 `~/.zshrc` 或使用 direnv。

## 5. 驗證安裝

```bash
which ocaml dune utop
ocaml -version && dune --version
echo 'let () = print_endline "ok"' > ok.ml
ocaml ok.ml   # 腳本模式直接執行
```

若 `utop` 中文亂碼，確認終端為 UTF-8（OCaml 5.3+ 原始碼預設 UTF-8）。

## 練習

1. 建立 `5.5.1` switch 並安裝 `dune`、`utop`。
2. 在 VS Code 開啟 `.ml` 檔，確認 LSP 有型別提示。

## 常見錯誤

| 症狀 | 原因與解法 |
| --- | --- |
| `dune: command not found` | 忘記 `eval $(opam env)` |
| `opam switch create` 卡住 | 缺少系統編譯器，先裝 `build-essential` / Xcode CLT |
| 舊版 4.x 與 5.x 混用 | `opam switch list` 確認目前 switch |
