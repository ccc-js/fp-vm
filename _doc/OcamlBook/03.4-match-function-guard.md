# 3.4 match、function 與守衛

模式匹配是 OCaml 的控制中樞：解構 + 分派 + 窮盡檢查一次完成。

## 1. match 基本形

```ocaml
let describe n =
  match n with
  | 0 -> "zero"
  | 1 -> "one"
  | _ -> "many"
```

分支由上而下嘗試，`_` 為萬用。編譯器檢查是否窮盡（exhaustive）與是否有冗餘（redundant）。

## 2. 解構各種結構

```ocaml
let sum = function
  | [] -> 0
  | h :: t -> h + List.fold_left ( + ) 0 t

let swap (a, b) = (b, a)

let show_user { name; age } = name ^ string_of_int age  (* 需 record 型別在 scope *)

let classify = function
  | Ok v -> "ok: " ^ string_of_int v
  | Error msg -> "err: " ^ msg
```

`as` 綁定整體、`|` 或模式、`when` 守衛：

```ocaml
let f = function
  | (x, y) as p when x = y -> Printf.sprintf "diag %d" x
  | (0, _) | (_, 0) -> "on axis"
  | p -> "other"
```

## 3. `function` vs `match` vs `fun`

```ocaml
let f1 = function Some x -> x | None -> 0   (* 單參數 match 糖 *)
let f2 x = match x with Some v -> v | None -> 0
let f3 = fun x -> x + 1                     (* 無匹配，純函式 *)
```

`function` 只能有一個參數（通常是 variant / list）。

## 4. 守衛與窮盡性技巧

```ocaml
type dir = N | S | E | W

let turn = function
  | N -> E
  | E -> S
  | S -> W
  | W -> N
(* 無需 _，編譯器驗證已窮盡；日後加分支會提醒補上 *)
```

若確實要部分匹配，用 `assert false` 或 `failwith` 並讓警告保留：

```ocaml
let hd = function
  | h :: _ -> h
  | [] -> invalid_arg "hd: empty"
```

`when` 會削弱窮盡檢查，盡量把條件編碼為模式：

```ocaml
(* 不佳：依賴 guard *)
let sign n = match n with x when x < 0 -> -1 | x when x > 0 -> 1 | _ -> 0
(* 較佳：先用 compare 轉為 variant *)
let sign n = match compare n 0 with -1 -> -1 | 1 -> 1 | _ -> 0
```

## 常見錯誤

- 把 `=` 寫成 `->` 外的 `=`，或忘記 `|`。
- 在 `match` 被匹配值後 quên `with`。
