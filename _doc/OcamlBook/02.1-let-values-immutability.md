# 2.1 let、值與不可變性

`let` 是 OCaml 的核心：綁定不可變的值，而非可變的變數。

## 1. 頂層與區域綁定

```ocaml
let pi = 3.14159          (* 頂層綁定，全域可見 *)
let x = 1

let area r =
  let pi = 3.14159 in     (* 區域綁定，遮蔽外層 *)
  pi *. r *. r
```

`let ... in` 是表達式，可嵌套：

```ocaml
let ring_area r1 r2 =
  let outer = 3.14159 *. r2 *. r2 in
  let inner = 3.14159 *. r1 *. r1 in
  outer -. inner
```

## 2. 不可變與遮蔽（shadowing）

```ocaml
let x = 1
let x = x + 1   (* 合法：新的 x 遮蔽舊的 x，舊值並未被修改 *)
```

這與命令式 `x = x + 1` 語義不同：OCaml 是創造新綁定，舊綁定在新作用域不可見。

真正可變需用 `ref`（第 4 章詳述）：

```ocaml
let c = ref 0
let () = c := !c + 1
```

## 3. `let () =` 的含義

```ocaml
let () = print_endline "hi"
```

表示「右側必須回傳 `unit`」。若函式回傳非 `unit` 卻寫 `let () =`，編譯器報錯，防止忽略回傳值。

## 4. 遞迴綁定 `let rec`

```ocaml
let rec fact n = if n <= 1 then 1 else n * fact (n - 1)
```

互相遞迴用 `and`：

```ocaml
let rec even n = if n = 0 then true else odd (n - 1)
and odd n = if n = 0 then false else even (n - 1)
```

## 5. 命名慣例

- 值與函式：`snake_case`，小寫開頭。
- 型別、模組、建構子：大寫開頭（`Option`、`Some`）。
- 私有輔助函式常以 `aux`、`go`、`loop` 命名。

## 練習

1. 用 `let ... in` 寫 `hypot a b = sqrt (a²+b²)`，浮點版。
2. 試著在 `utop` 重複 `let x = ...`，觀察 `#show x` 的變化。
3. 寫錯 `let () = 42`，記下錯誤訊息。

## 常見錯誤

- `Syntax error`：`let` 在函式內 quên `in`。
- 以為 `let x = x + 1` 會改變舊 `x` 在其他閉包中的值（不會）。
