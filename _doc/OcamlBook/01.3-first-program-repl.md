# 1.3 第一個程式與 REPL

學會用 `utop` 做實驗、用檔案寫第一支程式。

## 1. utop 入門

```bash
utop
```

在提示符後輸入（記得以 `;;` 結尾，或用 Ctrl+Enter）：

```ocaml
1 + 2 ;;
(* - : int = 3 *)

let greeting = "Hello, OCaml!" ;;
(* val greeting : string = "Hello, OCaml!" *)

print_endline greeting ;;
(* Hello, OCaml! *)
(* - : unit = () *)
```

`utop` 會回顯每個定義的型別與值，這是學習型別推論最快的方式。

常用鍵：

- `Alt+Enter`：多行編輯。
- `#show List.map;;`：查詢值資訊。
- `#require "unix";;`：載入函式庫。
- Ctrl+D 離開。

## 2. 第一個檔案

`hello.ml`：

```ocaml
let () = print_endline "Hello, OCaml 5.5!"
```

三種執行方式：

```bash
ocaml hello.ml          # 直譯執行（學習期最方便）
ocamlopt hello.ml -o hello && ./hello
ocamlc hello.ml -o hello.byte && ocamlrun hello.byte
```

## 3. 表達式 vs 陳述式

OCaml 幾乎一切皆為表達式，回傳值。`let () = ...` 表示「此式回傳 `unit`」：

```ocaml
let x = 1 + 2 in
let y = x * 10 in
Printf.printf "x=%d y=%d\n" x y
```

在頂層檔案中，每個 `let` 依序執行，副作用（列印）按順序發生。

## 4. Printf 速覽

```ocaml
Printf.printf "%d + %d = %d\n" 1 2 3
Printf.printf "%s has %d chars\n" "hi" 2
Printf.printf "%.2f %b\n" 3.14159 true
print_endline (Printf.sprintf "%05d" 42)
```

`printf` 直接輸出，`sprintf` 回傳字串。格式符與參數個數不符會在編譯期報錯。

## 練習

1. 在 `utop` 定義 `let pi = 3.14159`，再算 `pi *. 2.0 *. 2.0`。
2. 寫 `greet.ml`，讀第一個命令列參數並印出 `Hello, <name>!`（提示：`Sys.argv`）。
3. 故意寫錯 `Printf.printf "%d" "hi"`，觀察編譯器錯誤。

## 常見錯誤

- 忘記 `;;` 在 `utop` 外的 `.ml` 不需要 `;;`。
- 整數與浮點運算子混用：`1 + 2.0` 錯誤，須用 `float_of_int` 或 `+.`。
