# 4.2 遞迴、尾遞迴與摺疊

OCaml 無 `return`/`break` 迴圈語義的主力是遞迴；寫好尾遞迴即高效迴圈。

## 1. 基本遞迴

```ocaml
let rec fact n = if n <= 1 then 1 else n * fact (n - 1)
let rec sum = function [] -> 0 | h :: t -> h + sum t
let rec fib n = if n < 2 then n else fib (n-1) + fib (n-2)
```

`fib` 指數複雜度，僅作教學；實務用迭代或記憶化。

## 2. 尾遞迴：累積器

尾呼叫（tail call）是函式最後一個動作，編譯器優化為跳轉，不長堆疊：

```ocaml
let sum_to n =
  let rec go i acc = if i > n then acc else go (i + 1) (acc + i) in
  go 1 0

let rec loop i acc = if i = 0 then acc else loop (i - 1) (acc + i)
let () = Printf.printf "%d\n" (loop 1_000_000 0)  (* 安全 *)
```

對比非尾遞迴（會爆堆疊）：

```ocaml
let rec depth n = if n = 0 then 0 else 1 + depth (n - 1)
(* depth 1_000_000 → Stack_overflow *)
```

改寫技巧：加 `acc` 參數，必要時最後 `List.rev` 一次（O(n) 但安全）：

```ocaml
let rev_map f l =
  let rec go acc = function [] -> List.rev acc | x :: xs -> go (f x :: acc) xs in
  go [] l
```

## 3. fold 即結構化遞迴

多數遞迴可用 `fold` 取代，更不易錯：

```ocaml
List.fold_left ( + ) 0 [1;2;3]        (* 左摺疊，尾遞迴，推薦 *)
List.fold_right (fun x acc -> x :: acc) [1;2;3] []  (* 右摺疊，非尾遞迴，注意大串列 *)
```

`fold_left` 參數順序 `f acc x`，`fold_right` 為 `f x acc`。

## 4. 命令式迴圈（偶爾用）

```ocaml
let total = ref 0 in
for i = 1 to 10 do total := !total + i * i done;

let cur = ref 27 and steps = ref 0 in
while !cur <> 1 do
  cur := (if !cur mod 2 = 0 then !cur / 2 else 3 * !cur + 1);
  incr steps
done
```

`for i = a to b` / `downto`，迴圈變數不可變。能用 `fold` 就不用 `ref`+迴圈。

## 練習

1. 將 `List.length` 改寫為尾遞迴版。
2. 用 `fold_left` 實作 `rev`、`map`。
3. 比較 `fold_left` 與 `fold_right` 在 `[1;2;3]` 上對 `(::)` 的結果差異。

## 常見錯誤

- 在累積器版忘記 `List.rev` 導致順序反轉。
- `fold_right` 用於百萬級串列爆堆疊：改 `fold_left` + `rev`。
