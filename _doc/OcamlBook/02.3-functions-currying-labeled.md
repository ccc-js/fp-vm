# 2.3 函式、柯里化與標號參數

OCaml 函式只接受一個參數；多參數是語法糖，本質為柯里化。

## 1. 定義與匿名函式

```ocaml
let square x = x * x
let add a b = a + b        (* 等價於 let add = fun a -> fun b -> a + b *)

let f = fun x -> x * 2
let g = function 0 -> "zero" | _ -> "nonzero"  (* 單參數 match 糖 *)
```

呼叫一律空白分隔，不用括號：

```ocaml
square 5                   (* 25 *)
add 3 4                    (* 7 *)
```

## 2. 柯里化與部分套用

```ocaml
let add a b = a + b
let add10 = add 10         (* int -> int *)
let () = Printf.printf "%d\n" (add10 5)  (* 15 *)

List.map (add 1) [1; 2; 3] (* [2; 3; 4] *)
```

運算子亦可作函式：`( + ) 1 2`、`List.fold_left ( + ) 0 [1;2;3]`。

管線 `|>` 讓部分套用可讀：

```ocaml
[1;2;3;4] |> List.filter (fun x -> x mod 2 = 1) |> List.map square
```

## 3. 標號與可選參數（官方特色）

```ocaml
let greet ~name ~greeting = greeting ^ ", " ^ name ^ "!"

greet ~name:"Ada" ~greeting:"Hello"     (* 可任意順序 *)
greet "Ada" "Hello"                     (* 亦可按位置呼叫，不建議混用 *)
```

可選參數給預設值：

```ocaml
let create_user ?(age=18) ~name () = Printf.sprintf "%s is %d" name age

create_user ~name:"Bob" ()              (* "Bob is 18" *)
create_user ~name:"Bob" ~age:30 ()      (* "Bob is 30" *)
```

> 結尾 `()` 是慣用法：避免可選參數在部分套用時無法確定是否結束。

## 4. 高階函式初見

```ocaml
let twice f x = f (f x)
let () = Printf.printf "%d\n" (twice square 2)  (* 16 *)

let compose f g x = f (g x)
let inc_then_double = compose (fun x -> x * 2) (fun x -> x + 1)
```

自訂中綴運算子：

```ocaml
let ( >> ) f g x = g (f x)
let h = (fun x -> x + 1) >> (fun x -> x * 2)
```

## 練習

1. 寫 `curry : ('a * 'b -> 'c) -> 'a -> 'b -> 'c` 與 `uncurry`。
2. 用標號參數寫 `~width ~height` 的矩形面積函式，並以不同順序呼叫。
3. 用 `( |> )` 重寫巢狀 `string_of_int (List.length (List.map f l))`。

## 常見錯誤

- `This function has type ... It is applied to too many arguments`：忘記柯里化已部分套用。
- 可選參數省略結尾 `()` 導致回傳函式而非值。
